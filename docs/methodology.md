# Rollingold 方法论

Rollingold 是行业/板块轮动研究工作台，不输出个股推荐、不生成自动交易指令，也不承诺收益。

## 价格相对轮动

价格端使用页面行业指数相对默认基准 `801003` 申万 A 指的相对强弱与动量：

- `price_x` / `rs_z_120`：相对强弱的滚动 z-score。
- `momentum_y` / `rs_mom_20_z`：20 日相对强弱变化的滚动 z-score。
- `rs_rank_pct`：同一日期行业横截面百分位。
- `rs_new_high_60`：相对强弱是否处于 60 日新高。

## 宽度、成交与风险

- `breadth_ma20`：行业内成分站上 MA20 的比例。
- `breadth_delta_1d` / `breadth_delta_5d`：宽度边际变化。
- `breadth_slope_5` / `breadth_slope_10`：宽度扩散速度。
- `amount_share`：页面行业成交额占全部页面行业成交额的比例。
- `vol_20`、`vol_60`、`drawdown_60`：风险与稳定性因子。

## 评分

`config/scoring.default.yaml` 包含两套配置：

- `default_v1`：保留旧版固定权重，用于兼容原始评分口径。
- `balanced_v2`：加入趋势、动量、宽度、成交、风险和数据质量贡献。

页面展示 `score_breakdown`，帮助用户看到分数来自哪些因子，也显示风险扣分和数据质量置信度。

## 阶段机

阶段标签包括：

- 低位修复
- 价格确认
- 趋势扩散
- 高位背离
- 动能衰退
- 弱势下行

阶段迁移只解释信号变化，不构成买卖建议。

## 回测

策略实验室使用申万行业指数收益做历史模拟，信号在盘后生成，默认下一交易日执行，并计入交易成本。ETF 只作为可投资替代参考，不用于默认回测收益。

所有回测结果均标注：历史模拟，不代表未来收益。
